# 3D 台球 · 中式八球

浏览器端 3D 台球游戏：玩家 vs AI，第一/第三人称视角可切换，物理与规格尽量拟真。

## 运行

```bash
cd billiards
npm install
npm run dev        # 打开 http://127.0.0.1:5173
```

其他命令：

```bash
npm test           # 物理与规则单元测试（vitest）
npm run typecheck  # TypeScript 类型检查
npm run build      # 生产构建（dist/）
```

## 玩法与操作

| 操作 | 方式 |
| --- | --- |
| 瞄准 | 第一人称：点击画面锁定鼠标后移动瞄准；第三人称：移动鼠标指向目标；滚轮 / ←→ 微调 |
| 击球 | 按住空格蓄力，松开击出（唯一击球方式） |
| 视角 | 第三人称下按住左键拖动旋转镜头；`V` 切换第一人称 / 第三人称 |
| 杆法 | 右下角球面控件点选击点（上=高杆、下=低杆、左右=塞，双击复位；第一人称先右键释放鼠标） |
| 辅助线 | `G` 开关；工具栏色板可切换颜色（白/绿/黄/红/青，自动记忆） |
| 声音 | `M` 静音 |
| 重开 | `R` |

规则为中式八球：开球进球不定组；开放球局首次合法进球定组；犯规（白球落袋、空杆、
首触对方球、无球碰库等）判对方全场自由球；清完己组后合法打进黑 8 获胜，提前打进或
打黑 8 时白球落袋告负；开球黑 8 进袋重摆。

## 拟真要点

- **规格**：9 尺台面（2540×1270mm 库边内沿）、57.15mm 球、角/中袋口宽、库边鼻高（球高的 63.5%）均按真实规格。
- **物理**（自研确定性求解器，1ms 固定子步）：
  - 滑动/纯滚动两阶段台呢摩擦（击点高度决定即时旋转，ω = 2.5·(b/R)·(v/R)，2/5R 击点即自然滚动）
  - 球-球碰撞含切向摩擦（throw 抛掷效应），恢复系数 0.945
  - 库边碰撞接触点高于球心，高/低杆与左右塞会真实改变反弹角与反弹距离
  - 袋口颚斜切几何：中袋惩罚大角度入射、角袋可洗袋回弹
- **AI**：枚举「目标球 × 袋口 × 力度 × 杆法」候选 → 无渲染快速仿真 → 规则引擎评分
  （进球合法性 + 白球走位），三档难度通过搜索密度与执行噪声区分。
- **音效**：Web Audio 实时合成（球碰球清脆 click、库边闷响、进袋滚动声），音量随撞击速度缩放。

## 代码结构

```
src/
  physics/   纯逻辑物理：spec(规格) table(几何) solver(求解器) rack(摆球) preview(圆扫描)
  rules/     中式八球状态机（evaluateShot 纯函数）
  render/    Three.js：场景/球桌建模/球体滚动姿态/球杆/辅助线/相机系统/程序纹理
  ai/        候选球路搜索与评分
  audio/     Web Audio 合成音效
  ui/        HUD（顶栏/力度条/杆法控件/toast/菜单）
  game.ts    游戏控制器：流程状态机、输入、事件驱动
tests/       vitest 单元测试（物理行为 + 规则判定）
```

物理与规则层不依赖渲染，可供 AI 以同一份代码做无头仿真（`settleWorld`）。

## 已知简化

- 开球犯规（少于 4 球碰库）判对方自由球，不提供"重新开球"选项
- 白球跳台在物理上不会发生（袋口区域有兜底捕获），不做相关判罚
- 音效为实时合成；如需替换，把 wav 放入 `public/sounds/`（ball-hit / cushion / pocket / cue-strike）即可自动优先加载
